# Terrarium art reference

## Required file
Place the **favorite Warm Ember** screenshot here:

```
docs/art/warm-ember-reference.png
```

That image is the only source of truth for skill `terrarium-art`.

## How to get it
1. Use the Warm Ember night cutaway the user marked favorite
   (3F hall + mid elevator/Chief + bottom pit patrol, cream robots, amber eyes, red Chief, candles, pine exterior).
2. Save a clean PNG (stage only is fine; full dashboard also OK).
3. Name it exactly `warm-ember-reference.png`.
